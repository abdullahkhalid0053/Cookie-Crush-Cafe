# Cookie Crush - Bakery & Café Website

## Project Description
**Cookie Crush** is a multi-page static business website designed for a bakery and café specializing in freshly baked cookies, custom cakes, and handcrafted coffees. Developed as our Information & Communication Technology (ICT) final semester project at FAST-NUCES (Chiniot-Faisalabad Campus), this project demonstrates semantic web structure, responsive layouts, and consistent UI styling using pure HTML5 and CSS3 without JavaScript.

## Website Pages & Features
* **Home (`index.html`):** Welcome hero section, navigation bar, featured best-sellers, combo deals, and store footer.
* **Menu (`menu.html`):** Categorized product cards for Cookies, Cakes, and Coffees, along with a combo pricing table.
* **About Us (`about.html`):** The Cookie Crush brand story, baking philosophy, and team highlights.
* **Contact Us (`contact.html`):** Store location details, opening hours, and a styled customer inquiry/order form.

## Technologies Used
* **HTML5** – Semantic page structure and multi-page navigation.
* **CSS3** – Custom styling, Flexbox/Grid layouts, hover animations, and responsive media queries.
